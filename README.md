### 📊 **Sales Performance Dashboard**

#### 

#### **📌 Project Overview**



The Sales Performance Dashboard is an interactive Excel-based Business Intelligence solution developed to analyze sales performance, profitability, target achievement, product contribution, regional performance, and sales executive effectiveness.



This dashboard enables management teams to monitor business performance through KPI-driven reporting and interactive visualizations.



#### **🎯 Business Objective**

**The objective of this dashboard is to:**



* Monitor sales revenue and profitability.
* Measure target achievement across the business.
* Analyze regional sales performance.
* Track product contribution to overall revenue.
* Identify top and bottom-performing sales executives.
* Provide actionable business insights through interactive reporting.

#### **🔄 Data Preparation**



**Power Query was used to:**



* Perform data cleaning.
* Standardize data types.
* Create Year, Month and Quarter dimensions.
* Create Profitability classifications.
* Create Revenue bands.
* Create Target Achievement indicators.



#### **⭐ Data Model**



A Star Schema Data Model was developed using Power Pivot.



###### **Relationships**

* Calendar → Sales
* Product Master → Sales



This structure improves reporting performance and allows efficient DAX calculations.
